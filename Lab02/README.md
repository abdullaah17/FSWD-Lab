# Full Stack Web Development - Lab 2

## Topic

Advanced CSS and Bootstrap Flex Utilities

## Technologies Used

- HTML5
- CSS3
- Bootstrap 5
- VS Code
- Git
- GitHub

## Concepts Covered

- Advanced CSS
- CSS Flexbox
- CSS Positioning
- CSS Display Properties
- CSS Pseudo-elements
- CSS Filters
- CSS Transitions
- CSS Transform
- Bootstrap Flex Utilities

## Project Description

This project demonstrates advanced CSS layout and styling
techniques together with Bootstrap Flex utilities.

## Project Structure

```
Lab02/
│
├── index.html
├── style.css
└── README.md
```

## Where Each Concept Is Implemented

| Concept | Location |
|---|---|
| Advanced CSS (box-shadow, gradient, object-fit) | `.hero-section`, `.profile-image`, `.skill-box` |
| CSS Flexbox | `.hero-content`, `.skills-container`, `.project-container` |
| Position: relative | `.profile-image-container`, `.profile-card`, `.position-card` |
| Position: absolute | `.online-badge`, `.profile-card::before`, `.featured-badge` |
| Position: sticky | Navbar (`sticky-top`) |
| Pseudo-elements | `.section-heading h2::after`, `.profile-card::before` |
| CSS Filters | `.profile-image` (saturate), `.grayscale img` |
| Transitions / Transform | `.skill-box:hover`, `.project-card:hover`, `.project-image:hover img` |
| Bootstrap Flex Utilities | Bootstrap Flex section (`d-flex justify-content-between align-items-center flex-wrap gap-3`) |
| Responsive Design | `@media (max-width: 768px)` |
